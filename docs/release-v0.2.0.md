# v0.2.0：扩展页面控件与菜单汉化

新增图片／视频／音频展开导航菜单、图片质量菜单、视频主要操作和码率菜单、音频部分固定控件、Cinema Studio 侧栏、特效参数、编辑空状态与 AI 网红参数标题。

关联弹窗通过已知控件的 `aria-controls` 限定范围，图片质量菜单还核对固定标题。辅助按钮只翻译指定的 `aria-label`，保留用户文件名 tooltip。修复弹层离树后网站回写同值中文的还原竞态。

仍是非官方、无关联项目，采用 MIT 许可。权限维持唯一 `storage`；词典完全本地，无外部翻译服务、网络请求或遥测，不读 cookies、令牌、付款数据，不修改提示词、作品或代码。

## 验证及限制

- 61 项自动化测试通过，覆盖动态更新、开关还原、重复执行、路由和关联弹窗变化、用户内容与输入保护。
- Chrome 原创多页面夹具已验证 7 个模拟页面；真实网站仅作固定控件只读观察。
- 本版未完成实际 Chrome 扩展加载及全站注入验证；尚未达到 100% 全站汉化。
- 素材库内部、广告工作室内部、上传后的编辑器、全部模型设置、账户／付款内容及其他新功能仍未覆盖。详见仓库覆盖矩阵与验证记录。

下载 `higgsfield-zh-cn-v0.2.0.zip`，核对旁边的 `.sha256` 文件，解压后在 Chrome 的 `chrome://extensions` 手动加载直接包含 `manifest.json` 的目录。源码安装请使用 `extension/`。

SHA-256：`1e876e5c9688602e565fea2e9664ab4d5539bdf58dfe925344460c307d180460`。

已安装 0.1.0 的用户：将新版扩展文件放入原加载目录，在扩展页点“重新加载”，再刷新 Higgsfield。保留唯一一个版本启用，避免重复内容脚本。完整步骤见 README。
