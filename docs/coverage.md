# 覆盖与验证范围

适用版本：0.1.0。页面结构观察日期：2026-10-09。

本记录只保留脱敏的路径、标签、类名和短界面文案。没有提交网页 HTML 原件、截图原件、账号信息、提示词、作品或付费素材。

## 真实页面只读观察

通过可用浏览器只读查看了 `https://higgsfield.ai/` 及 `https://higgsfield.ai/ai/image?model=gpt_image_2`。未进行付费生成，也未修改用户作品。

| 范围 | 观察到的结构或文案 | 首版处理方向 |
| --- | --- | --- |
| 全局导航 | `.hfnav-item`、`.hfnav-action` 与资产入口链接 | 在明确导航控件内做精确词典匹配 |
| 图像生成页面 | `main fieldset` 中特定按钮内的文本容器：生成按钮的 `div:first-child`，及设置按钮的 `span.text-caption-l > div.flex` | 使用严格的类名与子元素选择器，配合 `ownText: true` 收录 `Auto`、`High`、`Generate` 等直接文本 |
| 品牌与模型 | 品牌及模型名称 | 保留原文 |

这些观察用于约束词典规则，并不证明扩展已经在真实页面中注入运行。本轮没有将扩展安装到用户浏览器，没有切换浏览器开发者模式，也没有完成全站实测。

生成规则不覆盖任意 `fieldset button` 或 `label`，也不递归进入这些按钮的后代内容。路由规则按路径边界匹配，只检查路径，查询参数不参与判断；例如 `/ai/image` 不会误匹配 `/ai/image-extra`。

## 自动化验证

测试使用 jsdom 及项目原创的合成 DOM，不包含下载的站点 DOM 或用户数据。应验证的核心行为包括：

- 只有指定选择器、路由及精确英文词典匹配时才翻译。
- 动态增加或更新控件后，异步观察器能处理已收录文案。
- 中英文开关可以还原扩展修改的文字。
- 重复执行保持稳定，不重复或叠加替换。
- 路由变化会重新检查规则适用范围。
- 输入框、可编辑内容、已知用户内容与文件名标记、代码及显式忽略区域保持原样。
- `ownText: true` 只翻译指定元素的直接文本，子元素、任意按钮及上传预览不因生成规则被递归翻译。
- 只有适用控件的 `title`、`aria-label` 可以翻译；输入值、占位文字、`alt`、URL、HTML 结构及未命中的文本保持原样。

执行 `npm test` 和 `npm run check` 查看当前代码的验证结果。测试通过代表合成夹具中的行为符合预期，不等于真实网站全部界面均受覆盖。

## 尚未覆盖或实测

| 界面或场景 | 状态 |
| --- | --- |
| 视频及其他生成路由 | 规则可沿用相同控件结构，但未进行真实页面注入验证 |
| 复杂 portal 弹出菜单 | 首版不保证覆盖 |
| Shadow DOM、iframe | 首版不覆盖 |
| 营销长文 | 不翻译 |
| 账户、账单及支付业务内容 | 不收录、不翻译；全局导航仍按导航规则处理 |
| 提示词、用户作品、代码、可编辑区域及文件名 | 已知结构与标记受保护；未知用户区域不能保证自动识别 |
| 后续网站改版或新控件 | 需重新观察及添加夹具，不能假定兼容 |

保护规则与收窄的选择器共同限制翻译范围，不能据此假定全站用户内容都会被自动识别。维护者新增覆盖时，应补充只读观察日期、最小结构描述与对应测试；真实页面没有访问权限或需要登录时，注明限制并继续使用原创合成夹具，不声称已完成实测。
